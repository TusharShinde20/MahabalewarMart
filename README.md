🍓 Mahabaleshwar Mart
Shop Local. Explore More.

Welcome to Mahabaleshwar Mart, a website built for a local strawberry farmer from Mahabaleshwar, Maharashtra, India.

Our website brings together local products, strawberry farming, shopping and travel inspiration. Customers can explore our product collection, learn about our farming journey and discover beautiful destinations around Mahabaleshwar.

🌿 About the Project

Mahabaleshwar Mart is a responsive website designed to showcase locally inspired products and connect customers directly with our small farming business.

The website provides an easy way to browse products, add items to a shopping cart, enter delivery details and send order enquiries.

✨ Features
🏠 Attractive homepage with animated strawberry farm-inspired design.
🍓 Product collection featuring jam, honey, syrup, crushes, mocktails and chikki.
🛒 Shopping cart with quantity management.
🔍 Product search, category filters and sorting.
📦 Checkout with customer and delivery details.
💳 Cash on Delivery and Google Pay payment options.
📧 EmailJS integration for email communication.
💬 WhatsApp ordering and customer support.
🧾 Order confirmation and printable bill.
🌄 Travel guide featuring places around Mahabaleshwar.
📝 Blog with farming stories and travel articles.
📱 Responsive design for mobile, tablet and desktop.
🎨 Interactive animations and visual effects.
🛠️ Technologies Used
HTML5 – Website structure.
CSS3 – Styling, responsive layouts and animations.
JavaScript – Website functionality and interactivity.
EmailJS – Email communication.
Google Fonts – Typography.
WhatsApp – Customer communication.
Google Maps – Location and travel directions.

🚀 How to Run the Project
Download or clone this repository.
Extract the project files if downloaded as ZIP.
Open the project folder.
Open index.html in your browser.

For local development, you can also use the VS Code Live Server extension.

📧 Email Configuration

The website uses EmailJS for email functionality.

To enable email sending:

Create an account at https://www.emailjs.com/
Create an Email Service.
Create an Email Template.
Configure your EmailJS Public Key, Service ID and Template ID in your JavaScript.
Make sure your template variables match the values sent by your JavaScript code.

Never put private email service credentials or secret keys in public JavaScript files.
